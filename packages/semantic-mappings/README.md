# MOEX Semantic Mappings

LinkML semantic properties, SSSOM mapping sets, and SKOS glossary projections.

Does **not** replace DAMS `Mapping` (conceptual/logical/physical). See
[docs/architecture/ontology-catalog.md](../../docs/architecture/ontology-catalog.md).

## Install

```bash
cd packages/semantic-mappings
pip install -e ".[dev]"
```

## Tests

```bash
pytest -v
```
