# Адреса и префиксы

У класса, поля и перечисления схемы DAMS есть постоянный адрес. Он нужен, чтобы [внешняя спецификация](glossary:external-specification) ссылалась на тот же предмет, даже если файл схемы в репозитории переехал.

Короткое имя перед адресом называют префиксом. База адресов — `https://data.moex.com/dams/`, короткое имя этой базы — `dams`. Адрес класса или поля складывается из базы и его имени. Отдельного файла со списком префиксов нет: список собирается из корневой схемы и подключённых к ней файлов. Корень лежит в `model-assets/specifications/moex-dams/0.1/schemas/moex-dams.yaml`.

Поля `class_uri` и `slot_uri` на классах самой схемы DAMS не заполняют. Их оставляют для ссылки на чужую спецификацию.

Смена базы, адреса префикса или имени, из которого складывается адрес, ломает уже выданные ссылки. Это ловит отдельная проверка адресов, цель `make ontology-check`. В общую проверку `make check` она не входит: для неё нужны дополнительные библиотеки. Отчёт по адресам даёт команда `moex-model ontology-report`.

Правило записано в [ADR-030](docs/adr/ADR-030-dams-uri-and-prefix-policy.md).
