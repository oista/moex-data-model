# Карта репозитория

Правьте модели в `model-assets/`. Там лежат стандарты, спецификации и реализации. Пример реализации — `model-assets/implementations/solutions/mdm/`.

Код, который читает и проверяет модели, лежит в `packages/`. Команды и просмотр — в `apps/`: программа `moex-model` в `apps/cli/`, просмотр публикаций в `apps/viewer/`, служебный интерфейс в `apps/api/`, отдельное веб-приложение в `apps/web/` и отдельное приложение схем `apps/drawdb/`.

Каталог `generated/` руками не правят. Туда сборка кладёт производные файлы: их можно выкинуть и получить снова из `model-assets/`.

Решения о том, как устроен продукт, лежат в `docs/adr/`. Длинное описание архитектуры — в `docs/architecture/`. Текст, который вы читаете, — в `docs/user/`.

Как устроены отдельные пакеты кода, на этой карте нет. Это следующий раздел документации.
