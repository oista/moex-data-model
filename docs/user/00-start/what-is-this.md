# Что это за продукт

Это репозиторий, в котором хранятся правила описания данных MOEX и конкретные модели, построенные по этим правилам.

Здесь можно:

- прочитать, как устроены стандарт, спецификация и реализация;
- проверить модель командами из репозитория;
- открыть собранный просмотрщик публикаций.

Этот раздел — краткое описание продукта **как он есть сейчас**. Он не вводит новых правил. Если текст расходится с принятым решением или с кодом, правят этот текст.

Полные разделы появятся позже. Пока здесь одна стартовая страница и три термина в [глоссарии](glossary:modeling-standard), чтобы работали сборка и проверка документации.
