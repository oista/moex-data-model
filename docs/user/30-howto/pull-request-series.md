# Серии правок

Большую переделку делят на отдельные правки. У каждой одна тема, и каждую можно прочитать саму по себе. Правило для людей и агентов лежит в `.cursor/rules/multi-pr-series.mdc`. Общая проверка это правило не выполняет. Зелёный `make check` на конечном дереве не доказывает, что промежуточная правка была целой.

В одной правке меняют только файлы её темы. Файлы следующей темы не трогают, даже когда итог всей серии уже ясен. Удобная форма — своя ветка на тему или отдельный коммит, который можно смотреть как одну правку.

Если план разводит изменение схемы и переписывание данных, их кладут в разные коммиты. Сначала остаётся состояние, где старые данные ещё проходят проверку. Последний шаг серии может снять устаревшее вместе с переносом данных и пересборкой производных файлов, но только когда это прямо записано в плане и в правиле. Самому такое совмещение не добавляют.

Где прочитать правило: [multi-pr-series.mdc](.cursor/rules/multi-pr-series.mdc).
