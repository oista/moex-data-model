# Топология

[Топология](glossary:topology) — чертёж систем, площадок и каналов, по которым ходят данные. Этот чертёж живёт не здесь. Его источник — внешняя система учёта (Clinkr/EAM).

В модели данных хранят ссылку на элемент чертежа и смысл, который к нему привязан: какие сущности и сообщения идут по этой связи. Копировать в YAML имена систем, класс интеграции и канал нельзя: при изменении чертежа копия разъедется с источником.

[Владение топологией](glossary:topology-ownership) поэтому разделено. Факты чертежа принадлежат внешней системе. Смысл данных принадлежит этой модели.

Где прочитать решение: [ADR-048](docs/adr/ADR-048-topology-ownership.md), [ADR-055](docs/adr/ADR-055-integration-source-of-truth.md).
