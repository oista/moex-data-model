- Separate collections preserve subclass types in pydantic: True

- JSON Schema: class-range refs remain `string` when `inlined: false` (no runtime class check). `SchemaNodeRef` pattern and minItems/maxItems **do** appear. Endpoint kind enforcement stays L2/L3.
- L1 designator: use `rules` with `equals_string` on mapping_type (not slot_usage equals_string on enum) so gen-shacl does not fail.
- Cross-instance resolve-and-check endpoint kind: L2 (DAMS validator), as with PDM-009 today.
- OWL: global `rdfs:range` of shared `source_refs` stays `uriorcurie`; subclass typing appears as class-local `owl:allValuesFrom` restrictions when ranges are classes.
- gen-shacl emits `sh:class` for class-ranged endpoint slots, but `SchemaNodeRef` pattern did **not** appear among `sh:pattern` lines — FieldMapping targets need a **manual L3** shape. Resolve-id→class remains L2 regardless.

**Chosen:** Variant B separate collections + Mapping subclasses with slot_usage; L1 rules for designator; endpoint kind in L2 + manual L3 SHACL (esp. SchemaNodeRef); do not put equals_string on enum slot_usage.
