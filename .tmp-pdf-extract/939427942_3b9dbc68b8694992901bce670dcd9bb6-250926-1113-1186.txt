Прочие endpoints
1. Сотрудники
1.1 Поиск сотрудника (POST /api/v1/employees/search-one)
Описание: Универсальный поиск сотрудника по одному из параметров: RowID, ID 1С, accountName или email.
Request Body ( ):EmployeeSearchDto
Поле Тип Описание Пример
rowId uuid Идентификатор записи в Docsvision8b282044-3612-4659-bfeb-a6bd83f31806
id1c uuid Идентификатор сотрудника в 1С 5667dfb7-ec95-4369-819e-52328b7d908a
accountName string Имя учётной записи AD nt_d\ivanov.ii
email string Электронная почта ivanov.ii@moex.com
Response ( ):EmployeeReadDto
Поле Тип Описание
rowId uuid Идентификатор записи в Docsvision
id1c uuid Идентификатор сотрудника в 1С
accountName string Имя учётной записи AD
email string Электронная почта
1.2 Поиск по имени учётной записи (POST /api/v1/employees/find-by-account-name)
Описание: Поиск сотрудника по имени учётной записи Active Directory.
Request Body ( ):AccountNameSearchDto
Поле Тип Обязательно Описание
accountName string Да Имя учётной записи AD
Response:  (см. выше)EmployeeReadDto

6. Статусы документов
6.1 Получить статусы (GET /api/v1/instance-status)
Description: Возвращает статусы документов из БД Docsvision, обновлённые после указанного времени. Используется для 
синхронизации статусов между сервисами.
Query Parameters:
Параметр Тип Обязательно Описание
lastUpdateddate-
time Да Время последнего обновления (ISO DateTime). Возвращает все записи, обновленные после 
этого времени.
Response (массив ):InstanceStatusDto
Поле Тип Описание
id uuid Идентификатор
lastupdated date-time Дата последнего обновления
doctype string Тип документа
status string Статус
