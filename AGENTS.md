# Агентам

Сначала читайте [docs/user/00-start/what-is-this.md](docs/user/00-start/what-is-this.md) и [docs/user/00-start/how-to-read.md](docs/user/00-start/how-to-read.md). Открываемый вид: [docs/user/index.html](docs/user/index.html).

При расхождении текстов правы, по порядку:

1. Accepted ADR в `docs/adr/`;
2. [docs/architecture/MODELING_ARCHITECTURE.md](docs/architecture/MODELING_ARCHITECTURE.md) и схемы;
3. код и `model-assets/`.

Страницу в `docs/user/` в этом случае исправляют. Черновики, `docs/migration/` и `.cursor/plans/` текущим состоянием продукта не являются.

Если PR меняет ADR, раскладку `apps/` / `packages/` / `model-assets/` или команды CLI — следуйте [.cursor/rules/user-docs.mdc](.cursor/rules/user-docs.mdc).
