# moex.hierarchy

Обобщённый вид иерархии сущностей DAMS по слоям **OWL → CDM → LDM**.

Это **производная публикация** (не источник истины): сущности и связи собираются
из enterprise conceptual model и моделей ИТ-решений. Атрибуты и физический
уровень не включаются.

## Разделы

- **Overview** — назначение и правила hop-окрестности
- **Entity hierarchy** — отбор сущностей (панель «Связи») и послойная визуализация
- **Артефакты** — полная спецификация DAMS (слитый LinkML), YAML полной
  обобщённой модели и конверт реализации

## Визуализация

По выбранным сущностям строится окрестность с независимым hop на каждом слое
(по умолчанию 1). Раскладка — elkjs (layered / orthogonal); выгрузка кадра —
SVG и PNG для презентаций и документации.
